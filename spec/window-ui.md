# 手机窗口镜像规则

> **延期研究（2026-10-31）**：当前 CodeLight 发行是 Codex 原生会话专用。本文件保留此前的窗口/AX 研究与验证边界，不表示当前已启用窗口共享或其他 harness。窗口 ID、截图与 AX 控件不计为 Codex session 支持；是否启用留待后续决定。当前范围以 [产品合同](codelight-product.md) 为准。

ZCode 无外部 Host attachment API，用户已接受辅助功能控制。因此它在手机中以真实桌面窗口呈现，窗口选择、草稿与当前会话同桌面共用，不把窗口ID或标题冒充CLI session ID。Codex仍使用原native owner/follower会话接口。

窗口图片只能经已配对的本机服务读取，目录和应用/窗口地址绑定。图片内容与对应captureStamp/控件列表一起发布；手机必须在图片加载完成后再激活同一版本的操作状态，不能用新stamp点击旧图片。慢连接只保留一个正在加载的图片和最新待加载版本。

Stage Manager把物理窗口缩为缩略图时，允许用已绑定的同PID逻辑AX窗口读取文字与语义控件。AX-only视图明确标识后台文字/控件模式，不把缩略图当完整图片；只启用已验证的AX输入/按压，坐标、滚轮与物理按键禁用。文字与控件必须来自同一个captureStamp版本。

切应用、切窗口、后台或连接失效后清掉旧窗口图和控件状态。屏幕锁状态与UI不可见状态分开显示：只有已确认locked才提示解锁；非前台AX窗口枚举为空则允许用户显式『显示ZCode』，按原PID合法main/focused window正常激活后重新读取，不重启、不增加调试参数。

指针坐标为窗口局部点，浏览器以已显示图片的长宽比映射captureStamp.bounds；放大与滚动不改变这一规则。填入文字只对用户选择的实际空输入框进行，不覆盖已有桌面草稿；填入不等于Agent已接收，手机需点击ZCode自身发送/入队控件。通用窗口按键或点击的回执仅证明UI操作，不能声明LLM业务admission。

Codex的新输入通过原生admission确认；未知命令结果保留原commandId并查回执，服务重启、网络故障不自动重发。两种方式的产品文案明确区分。

开始之前

支持哪些设备和 Codex 连接方式？

公开 Mac 版本面向 Apple Silicon、macOS 14+，只支持使用网关模式接入的桌面 Codex。iPhone 客户端目前需要从源码构建；其他 harness、Intel Mac、Windows 和 Linux 不属于本次发行范围。

为什么暂时没有 iPhone 下载按钮？

手机端尚无公开 App Store 或 TestFlight 发行。开发签名 IPA 只适用于已登记设备，也可能包含设备信息，所以不作为公共下载提供。你可以从开源仓库构建手机端。

连接断开了怎么办？

手机会自动尝试可用连接，也能手动切换。Mac 重启可能改变本地地址/端口或 Cloudflare 临时地址；Relay 的认证路径在重连后保持。全部已存地址不可用时再扫描当前二维码。未知操作只查询原编号回执，不自动重发。

可以使用自己的公网 Relay 吗？

可以。在 Mac 的“配置 Relay”填写兼容服务的 HTTPS 地址和访问密钥，校验后保存并显示复选框。Relay 可与本地网络、Cloudflare 同时启用；手机继续扫码，无需填写服务器。公网 Relay 只转发流量，会话、密钥和任务状态仍由 Mac 保有。

“未确认”和流量统计分别代表什么？

“未确认”表示尚未取得可靠的原会话状态，不能按空闲或零处理。流量统计覆盖 CodeLight 自有网关的 HTTP/WebSocket 接口字节，不包含外部 TLS/IP 开销或模型 token。

这是 Codex 官方产品吗？

CodeLight 是独立开源项目，基于 Happy 的 MIT 组件构建，不隶属于 OpenAI。桌面原生接口可能随 Codex 版本变化；尚未支持的接口会明确显示不可用。
